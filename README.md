# Discord Auto Quest Web Extension

A simple Chrome extension that helps automate Discord quests.

## Installation

### 1. Clone the Repository

```bash id="j4m8x2"
git clone https://github.com/whisker-kisses/Discord-Auto-Quest--Web-Extension.git
```

Or download the repository as a ZIP and extract it anywhere on your PC.

### 2. Open Chrome Extensions

Go to:

```text id="f8q2n1"
chrome://extensions
```

### 3. Enable Developer Mode

Turn on **Developer Mode** from the top-right corner.

### 4. Load the Extension

Click **Load Unpacked** and select the folder where you cloned or extracted the repository.

### 5. Done

The extension is now installed and ready to use.
